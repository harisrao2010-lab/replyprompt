# ReplyPrompt

A free, privacy-first prompt builder for customer-service replies. It runs entirely in the visitor's browser and does not call an AI API; visitors copy the prompt into their preferred AI chat service and review the result themselves.

## Files
- `index.html` — responsive prompt builder and guidance
- `favicon.svg` — site icon
- `robots.txt` and `sitemap.xml` — basic crawler discovery files

## Publishing
This static site is intended for GitHub Pages at `https://harisrao2010-lab.github.io/replyprompt/`. It has no build step, external dependencies, analytics, or server-side form handling.

## Search notes
The page uses descriptive titles and natural language for its subject. It intentionally avoids a `meta keywords` tag and keyword stuffing. No search volume, ranking, traffic, or revenue is guaranteed.
